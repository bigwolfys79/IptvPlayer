# IptvPlayer

## Лицензия

Этот проект распространяется под лицензией **Prosperity Public License 3.0.0**.

Он бесплатен для некоммерческого и личного использования, но коммерческое использование ограничено 30-дневным пробным периодом. Для получения более подробной информации см. файл [LICENSE](LICENSE).

IPTV-плеер для плейлистов M3U/M3U8 с архивом (timeshift) и полноценным HEVC/AC-3 воспроизведением на базе FFmpeg. WinUI 3 / .NET 8 / Windows App SDK.

- **Версия:** 1.12.1
- **Репозиторий и релизы:** https://github.com/bigwolfys79/IptvPlayer (проверка обновлений встроена в «О программе»)
- **Настройки и кэш:** `%LocalAppData%\IptvPlayer`
- **Лог (Serilog):** `%LocalAppData%\IptvPlayer\logs` (ежедневный роллинг, включается/выключается в настройках)
- **Сборка Debug:** MSIX (F5 в Visual Studio, Platform=x64)
- **Сборка Release + инсталятор:**
  ```
  dotnet publish IptvPlayer.csproj -c Release -p:PublishProfile=win-x64
  "%LOCALAPPDATA%\Programs\Inno Setup 7\ISCC.exe" installer\IptvPlayer.iss

или & "$env:LOCALAPPDATA\Programs\Inno Setup 7\ISCC.exe" installer\IptvPlayer.iss
  ```
  Готовый файл: `installer\output\IptvPlayer-Setup-<версия>-x64.exe`

## Реализовано

### v1.12.1
- **Ключи больше не хранятся открытым текстом** — ключ портала и URL плейлистов/EPG-источников (в которых обычно зашиты логин, пароль или токен) шифруются через DPAPI Windows и записываются в settings.json в виде непрозрачных строк `dpapi:...`; существующие настройки мигрируют автоматически при первом сохранении.
- **Убран дублирующийся секрет из вспомогательных хранилищ** — поле "key" больше не пишется в SQLite-кэш каналов (при отправке запроса порталу ключ подставляется заново из настроек), а ключи и пароли маскируются в файловом логе и portal_dump.
- **Кнопка «Скачать и установить» в «О программе»** — при ручной проверке обновлений найденная версия превращает кнопку проверки в «Скачать и установить»: установщик скачивается во временную папку (с проверкой SHA256 и прогрессом), затем запускается тот же сценарий, что и при автопроверке (диалог согласия, откладывание при активных записях, тихая установка). Дублирующий код запроса к GitHub в диалоге убран.
- **Убран комбобокс сортировки списка каналов** («по каталогу / по имени / по году») — порядок всегда как в источнике, избранное остаётся наверху.
- **Ссылки плейлистов скрыты в настройках** — в списке плейлистов значения username/password/token в ссылке показываются как «***» (сами EPG-ссылки не тронуты).

### v1.12.0
- **Возобновление просмотра фильмов портала** — при повторном открытии фильма/серии, если раньше вы остановились позже 30 секунд от начала (и не у самого конца), появляется диалог «Продолжить / Смотреть сначала» с указанием времени остановки (например, «вы остановились на 25:53»). Позиция помнится для каждого фильма отдельно, у сериалов — для каждой серии своя; хранится в настройках (до 200 последних), запись в файл прорежена (не чаще раза в 5 секунд), досмотренное до конца вытесняется автоматически. Возобновление — прямой перемоткой медиа-движка, без рестарта потока.
- **Понятная подсказка на ползунке перемотки** — при перетаскивании полосы перемотки VOD всплывающая подсказка над бегунком показывает время в формате ч:мм:сс (раньше — сырые секунды: «3360» вместо «0:56:00»).

### v1.11.6
- **EPG как отдельное окно** — панель EPG вынесена на уровень всего окна (раньше только в области видео): затемнение покрывает весь экран (включая список каналов), клик вне панели закрывает EPG. В оконном и полноэкранном режимах полноэкранный оверлей не перехватывает мышь при открытом EPG. Колесо мыши при открытом EPG работает только для прокрутки списка передач.
- **Упрощён механизм скрытия курсора** — вместо итерации по subtree и установки `ProtectedCursor` на каждый элемент по отдельности, курсор прячется одним присваиванием на корневом `CursorGrid` (protected-свойство действует на весь subtree по документации WinUI). Удалены `CreateHiddenCursor()`, `_sharedHiddenCursor`, словарь `_hiddenCursorByElement`, методы `EnumerateVisualTree()` и `VideoAreaDescendants()`.
- **Курсор виден над EPG в fullscreen** — при открытии EPG-панели в полноэкранном режиме курсор корректно показывается (ранее прятался вместе с оверлеем); при закрытии EPG скрытие возвращается автоматически по таймеру оверлея.
- **Serilog в оверлеях и курсоре** — все методы показа/скрытия оверлея, управления курсором и CursorHider логируются статическим `Serilog.Log`; каждое действие (показ/скрытие, нудж, fade-in/out, создание CursorHider, пробуждение курсора) фиксируется с параметрами.

### Воспроизведение
- **FFmpegInteropX + FFmpeg** — демуксинг и декодирование любых потоков (включая HEVC в MPEG-TS и AC-3, которые системный плеер Windows не тянет); рендер — штатный MediaPlayerElement.
- Режимы декодирования видео, переключаются в настройках: аппаратный (GPU с откатом на CPU) и программный (CPU, по умолчанию — плавно даже на 1080p60).
- Упреждающая буферизация (15 с / 32 МБ) — устраняет замирания на стыках 10-секундных HLS-сегментов.
- Громкость: слайдер в панели управления, колесо мыши над видео, сохраняется между запусками; многоканальный звук (5.1) сводится аудиодвижком Windows (не тихий downmix FFmpeg).
- **Режимы отображения видео**: вписать (letterbox, по умолчанию) / растянуть / обрезать (масштаб с сохранением пропорций, выступающее за края отсекается) — для контента не в пропорции окна (4:3 на 16:9); кнопка в обеих панелях управления и клавиша V, текущий режим — в подсказке кнопки, выбор сохраняется в настройках.
- **Оверлей статистики (Ctrl+J, как в VLC)**: кодеки видео/аудио, разрешение, fps, битрейты, фактический декодер видео (FFmpeg D3D11 GPU / FFmpeg CPU / системный — как выбрал FFmpegInteropX, включая откат в аппаратном режиме) и статус аппаратного декодера на машине, глубина буфера, число простоев буферизации и время сессии канала (живая строка — тикает каждую секунду) — для диагностики «тормозит» достаточно скриншота оверлея; работает в оконном и полноэкранном режимах (в fullscreen — под шапкой с названием канала, правее списка каналов). Включается/выключается также тумблером «Статистика потока» в настройках (Диагностика), состояние переживает перезапуск.
- **Горячие клавиши и беззвучный режим**: пробел — пауза/продолжение архива; ↑/↓ и PgUp/PgDn — соседний канал по кругу в пределах текущего фильтра (в полноэкранном режиме оверлей показывается, чтобы было видно, куда переключились); M — без звука с кнопками mute в обеих панелях управления (слайдеры показывают ноль, громкость восстанавливается при снятии); F/F11 и двойной клик по видео — полный экран; Esc — выход из него; Ctrl+F — фокус в поиск с выделением текста; V — режим отображения; Ctrl+J — статистика потока; цифры — прямой ввод номера канала с оверлеем как в телевизоре (Enter или 3 с — коммит, Backspace — стереть, Esc — отмена). Буквенные клавиши работают в любой раскладке (VK-коды); в полях ввода и открытых диалогах горячие клавиши не действуют; стрелки/PageUp/PageDown не перехватываются, когда фокус на списке, слайдере перемотки или комбобоксе.
- Архив (timeshift): клик по передаче запускает её с начала; кнопки «В эфир» и пауза появляются в панели управления во время архива.
- **Перемотка архива**: полоса с подписями времени в панелях управления (оконной и полноэкранной) во время архивного показа — вся полоса изображает передачу целиком (ноль — её начало), отпускание ползунка перезапускает поток с новой точки (HLS-timeshift не ищется на лету); позиция и паузы считаются по часам, после перемотки индикатор остаётся на выбранной минуте, дальше живого эфира уйти нельзя.
- **Прогресс текущей передачи**: тонкая полоса в строке канала (главный список и полноэкранный оверлей — общий шаблон) и в шапке полноэкранного оверлея — видно, сколько передачи уже прошло; обновляется каждые 30 с.
- Стабильность: источник FFmpeg привязан ко времени жизни плеера (ConditionalWeakTable) — устранён крах 0xC00D36B6 с пропаданием звука/видео; ошибки плеера пишутся в лог с кодами (MediaPlayer.MediaFailed); для HLS отключён keepalive (`http_persistent=0` — некоторые провайдеры чередуют сервера сегментов, и переиспользование соединения ломалось на каждом сегменте, вызывая затыки) и включено авто-восстановление соединения (`reconnect`).

### Видеотека (видео-портал)
- **Источник-портал в списке плейлистов**: тип «Видео-портал» в диалоге «Плейлист»; понимает комбинированную строку портала целиком (`portal::[key:...]URL`) — ключ и базовый адрес API вычленяются автоматически, либо вводятся по отдельности. Каталог портала (категории → фильмы/сериалы с пагинацией) становится «плейлистом»: категории = группы в фильтре, элементы = каналы; кэшируется как обычный плейлист.
- **Воспроизведение VOD**: клик по фильму запрашивает у API поток лениво (ссылки короткоживущие, не кэшируются); VOD-режим — пауза пробелом без рестарта потока, полоса перемотки с позицией/длительностью (перемотка на лету, без перезапуска); у сериалов поток первого сезона/эпизода (выбор серий — в планах).
- **Сезоны и серии**: клик по сериалу открывает диалог с постером, описанием, комбобоксом сезона (сезоны — отдельные карточки каталога, группируются по названию сериала) и списком серий. Во время просмотра в нижних панелях (оконной и полноэкранной) — комбобоксы «Сезон» и «Серия»: переключение серии мгновенное, без повторного запроса к порталу. Кнопка EPG при просмотре портала скрыта.
- **Сетка постеров**: переключатель вида списка (строки ↔ плитки с постерами) рядом с фильтром групп; постеры из каталога портала, виртуализация и декодирование уменьшенно — каталог в 20k+ элементов листается плавно; поиск/фильтр/сортировка работают в обоих видах, выбор запоминается.
- **Выбор качества**: меню на кнопке в нижних панелях (480p/720p/1080p/Авто) — варианты отдаёт портал; переключение перезапускает поток с той же позиции; стартовое качество — из настройки «Предпочтительное качество».
- **Описания**: аннотация фильма портала — в шапках над видео (оконной и полноэкранной, целиком под полосой прогресса) и во всплывающей подсказке при наведении на элемент в списке.
- **Быстрый старт фильмов**: фильм начинается сразу по ссылке каталога (без ожидания запроса к порталу), варианты качества догружаются в фоне и подкладываются в играющий плеер; отдельный настраиваемый буфер видеотеки («Воспроизведение» → «Буфер видеотеки», 2–15 с, по умолчанию 4) — эфирный буфер 15 с на медленном CDN держал старт по несколько секунд.
- **Производительность на больших каталогах**: пересборка списка (поиск/фильтр/сортировка) — одной операцией вместо десятков тысяч событий; полноэкранная группировка строится только при входе в fullscreen; скрытый вид (список ↔ постеры) отсоединяется от данных.
- **Сортировка каталога**: по каталогу (порядок портала) / по имени / по году — комбобокс рядом с фильтром групп; поиск по каталогу с дебаунсом 300 мс (22 000+ элементов не вешают UI).
- Протокол клиента «прозрачный»: request-объекты API передаются как есть, все ответы разбираются мягко (неизвестные поля игнорируются), каждый запрос/ответ логируется — новые команды портала не требуют правок клиента.

### Интерфейс
- Видео занимает всю правую область.
- Панель управления видео (громкость, пауза архива, «В эфир», настройки, полноэкранный режим) появляется по движению мыши и скрывается сама через 3 с; работает в оконном и полноэкранном режимах; исправлено появление «только после остановки мыши».
- **Трей**: иконка в системном трее показывается только пока окно скрыто — при закрытии в трей (крестик, настройка) или сворачивании в трей (кнопка «Свернуть», отдельная настройка); когда окно видно — только значок в панели задач. Левый клик по иконке возвращает окно, правый — меню «Показать/Выход».
- **Полноэкранный режим без полей**: видео занимает весь экран от края до края (декоративная рамка-отступ контейнера видео, ~3 мм, в fullscreen убирается и возвращается в оконном режиме).
- **Полноэкранный режим**: текущий канал подсвечен в списке оверлея и прокручен в верхнюю видимую строку; курсор мыши автоматически исчезает вместе с оверлеем после 3 с бездействия (в т.ч. над видео) — движение мыши, одиночный и двойной клик и колесо громкости работают и в спрятанном состоянии.
- Убраны: постоянная панель над плеером, баннер архива поверх видео.
- Настройки — отдельными диалогами из меню шестерёнки: «Воспроизведение» (декодер, буфер, качество, нормализация громкости), «Интерфейс» (язык, тема, таймер сна, трей, файловый лог), «Плейлист» (несколько плейлистов), «Записи», «Родительский контроль», «О программе» (описание, пути, проверка обновлений с GitHub Releases).
- Список каналов отображается сразу при запуске.
- **EPG (XMLTV)**: источники на каждый плейлист (свой список в диалоге «Плейлист», фолбэк — глобальный источник по умолчанию), сопоставление каналов по tvg-id и по нормализованному имени; описание текущей передачи — в шапках над видео (под названием, целиком), описания всех передач — в EPG-списке. В v1.9.0 исправлен давний баг парсера XMLTV: чтение на subtree-ридере съедало всё после первого элемента — desc/category/иконки терялись всегда (теперь большинство передач фида с аннотациями); версия дискового кэша EPG поднята — при первом запуске фид перекачается один раз.
- Индикатор архива передач в списке каналов: зелёная точка у каналов с архивом (атрибут `tvg-rec`/`catchup-days` плейлиста), серая — без архива; подсказка показывает глубину архива в днях.
- **Напоминания о передачах**: колокольчик в карточке будущей передачи → тост Windows за N минут до начала (настраивается в настройках, по умолчанию 5; `CommunityToolkit.WinUI.Notifications`). Напоминания переживают перезапуск, устаревшие чистятся автоматически.
- **Избранные каналы**: звёздочка в списке (закрашенная/контурная), избранные всегда наверху списка и в группе «★ Избранное» полноэкранного оверлея, есть фильтр по избранному; хранятся по имени канала в настройках.
- **Полуавтоматическое обновление** (тумблер в «Интерфейсе», по умолчанию включён): через пару минут после запуска — не чаще раза в сутки — приложение само проверяет GitHub Releases, скачивает установщик с проверкой SHA256 и предлагает установить; установка тихая (приложение закроется и вернётся само), не запускается, пока идут записи передач (дождётся окончания и поставит), при любой ошибке текущая версия продолжает работать. UAC-подтверждение установки остаётся (установка в Program Files).
- **Автопродолжение**: при запуске выбирается и включается последний смотренный канал; восстанавливается и его группа в фильтре списка (канал виден в своём подразделе), список прокручивается к нему.
- **Тёмная тема**: Светлая/Тёмная/Системная через FrameworkElement.RequestedTheme — применяется на лету (на старте и сразу при смене в настройках).
- **Язык интерфейса** (Русский/English): локализатор Services/Localizer.cs, пары строк в местах использования; переключение действует сразу.
- **Слайдер буфера видео** в настройках (5–60 с): управляет ReadAheadBuffer FFmpeg — плавность против задержки от эфира.
- **Живой разделитель панелей**: ширина списка каналов тянется мышью (CommunityToolkit Sizers, 240–640 px) и запоминается.
- **Память окна**: позиция, размер и развёрнутость окна восстанавливаются при запуске (нативный AppWindow.MoveAndResize, с вписыванием в рабочий стол при отключённом мониторе).
- **MVVM-рефакторинг (этапы 1–3)**: ViewModel'и (`MainPageViewModel`, `EpgViewModel`, `PlayerViewModel`, `ChannelViewModel`) на `ObservableObject` со свойствами через `SetProperty` — `[ObservableProperty]` сознательно не используется (генератор не создаёт WinRT-проекторов — MVVMTK0045, важно для AOT/ABI). Действия пользователя — на `[RelayCommand]`. Code-behind MainPage разбит по зонам на partial-файлы (`MainPage.FullScreen.cs`, `MainPage.Overlays.cs`, `MainPage.Hotkeys.cs`, `MainPage.StatsOverlay.cs`). Ядро MainPage — ~1900 строк.
- **Запись передач и каналов**: до 3 параллельных записей (ffmpeg `-c copy`, аккуратная остановка по `q`), кнопка REC в панелях управления; папка настраивается (меню «Записи»), активные/запланированные видны там же; прерванные закрытием приложения записи предлагается продолжить при следующем запуске.
- **Serilog + DI**: вместо самописного файлового логгера — Serilog (Debug-вывод + файл в `%LocalAppData%\IptvPlayer\logs` с ежедневным роллингом, 14 дней хранения; тумблер в настройках действует на лету), классы получают `ILogger<T>` конструктором; зависимости собирает `Microsoft.Extensions.DependencyInjection` (composition root в `App`, `App.Services`) — все `?? new …`-фолбэки и разрозненные `new SettingsService()` убраны, сервисы и ViewModel'ы — singletons.
- Записи хранятся в MPEG-TS без перекодирования; папка по умолчанию — «Видео\IptvPlayer», настраивается.
- Иконка приложения (окно, инсталятор, все MSIX-логотипы) — `Assets/AppIcon.ico`; генератор логотипов: `analysis/gen-icons.ps1`.
- **Трей**: крестик сворачивает окно в трей — воспроизведение продолжается (нативный Shell_NotifyIcon; левый клик — показать, правый — меню «Показать/Выход»); полный выход мгновенный (остановка плеера и записей + немедленный выход процесса). Настраивается тумблером в «Интерфейсе».
- **Мини-плеер (Ctrl+M)**: компактное always-on-top окно 480×300 поверх всех окон, панели скрыты.
- **«Предыдущий канал»**: кнопка «←» в обеих панелях и Backspace — возврат по сессионной истории просмотров.
- **Родительский контроль**: запуск каналов выбранных групп требует PIN (PBKDF2-хэш); при вводе предлагается отключить запрос на 15/30/45/60 мин или до выключения.

### Инфраструктура
- Release собирается unpackaged (`WindowsPackageType=None` + `WindowsAppSDKSelfContained`) под классический установщик; Debug остаётся MSIX для F5.
- Инсталятор Inno Setup (`installer/IptvPlayer.iss`): мастер с выбором языка установки (русский/английский — диалог выбора при запуске), иконки, lzma2, встроенные декодеры Dolby AC-3/AC-4 (тихо ставятся при отсутствии, с проверкой).
- `installer/Install-DolbyDecoders.ps1` — автономная установка декодеров Dolby (Microsoft Store → при отказе региона: сайдлоад с зеркала).
- Скрипты в `analysis/`: генератор иконок, TS-пробер кодеков, измерения громкости/скорости.
- Настройки и кэш в `%LocalAppData%\IptvPlayer` (работает и в MSIX, и unpackaged); файловый лог с ротацией.

## Известные особенности

- Задержка от живого эфира ~10–15 с (плата за упреждающую буферизацию против замираний на стыках сегментов; при необходимости уменьшить `ReadAheadBufferDuration` в `StreamService`).
- MSIX-версия (Debug) и Inno-версия — «разные приложения» с общими настройками; удаляйте одну, чтобы не путаться в ярлыках.
- Файловый лог по умолчанию включён и пишется в `%LocalAppData%\IptvPlayer\logs` (ежедневный роллинг); выключается тумблером «Файловый лог» в настройках — действует сразу, вывод в Debug (окно Output) остаётся всегда.
