**Купленная лицензия активируется офлайн, без сервера:** пункт меню «Лицензия» (перед «О программе», также в меню настроек хаба) показывает текущий статус — личное использование, коммерческую лицензию (на кого зарегистрирована и на какой срок) или остаток пробного периода. Там же кнопка активации: скопируйте «Код железа (HWID)», пришлите разработчику и вставьте полученный ключ в диалог (или импортируйте файл `.lic`). Активация доступна в любой момент, не дожидаясь конца триала. Ключ подписан RSA-2048 и привязан к HWID — подделать его без приватного ключа разработчика нельзя.

IPTV-плеер для плейлистов M3U/M3U8 с архивом (timeshift) и полноценным HEVC/AC-3 воспроизведением на базе FFmpeg. WinUI 3 / .NET 8 / Windows App SDK.

- **Версия:** 1.22.0
- **Репозиторий и релизы:** https://github.com/bigwolfys79/IptvPlayer (проверка обновлений встроена в «О программе»)
- **Настройки и кэш:** `%LocalAppData%\IptvPlayer`
- **Лог (Serilog):** `%LocalAppData%\IptvPlayer\logs` (ежедневный роллинг, включается/выключается в настройках)
- **Сборка Debug:** MSIX (F5 в Visual Studio, Platform=x64)
- **Сборка Release + инсталятор:**
  ```
  dotnet publish IptvPlayer.csproj -c Release -p:PublishProfile=win-x64
  "%LOCALAPPDATA%\Programs\Inno Setup 7\ISCC.exe" installer\IptvPlayer.iss
  ```
  Готовый файл: `installer\output\IptvPlayer-Setup-<версия>-x64.exe`

## Возможности

### Воспроизведение
- FFmpegInteropX + FFmpeg — декодирование HEVC, AC-3 и других кодеков
- Аппаратный (GPU) и программный (CPU) режимы декодирования
- Упреждающая буферизация (15 с / 32 МБ)
- Режимы отображения видео: вписать / растянуть / обрезать
- Рендер-апскейл (эксперимент): D3D11 Video Processor (RTX VSR / Intel VSR при поддержке драйвера), FSR 1.0, бикубик — с автоматическим фолбэком
- Нормализация громкости: Dynamic (усиление тихих) / Loudness (EBU R128)
- Усиление громкости до 200 % (FFmpeg volume поверх нормализации — для очень тихих каналов)
- Тосты-подтверждения действий внизу по центру видео: громкость, звук, таймер сна
- Замер реальной скорости потока через диагностический прокси (настройки воспроизведения)
- Оверлей статистики (Ctrl+J): кодеки, разрешение, битрейты, декодер
- Горячие клавиши: цифры (номер канала), Enter (подтвердить), Backspace (предыдущий канал), стрелки/PgUp/PgDn (соседний канал), пробел (пауза архива и VOD), M (без звука), V (режим отображения), F/F11 (полный экран), Esc (назад/выход), Ctrl+F (поиск), Ctrl+J (статистика потока), Ctrl+M (мини-плеер), Ctrl+T (окно поверх всех окон); полная справка — F1
- Архив (timeshift) с перемоткой и прогрессом текущей передачи
- Пауза архива/VOD замораживает последний кадр (без «серого экрана»), при смене состояния паузы — всплывающий индикатор «Пауза / Воспроизведение»
- Диагностика при ошибке воспроизведения (проверка URL потока)

### Локальные видеофайлы
- Карточка «Видео» на хабе — открытие видеофайла с диска (FileOpenPicker: mp4, mkv, avi, ts, mpg и др.)
- Воспроизведение тем же конвейером, что VOD: пауза, перемотка, полный экран, нормализация громкости
- Поддержка кириллицы и пробелов в путях; запуск с видеофайлом в аргументе командной строки

### Видеотека (видео-портал)
- Hub Page с приветствием, анимацией и кастомными flyout-меню
- Источник-портал с каталогом категорий, фильмов и сериалов
- Воспроизведение VOD с паузой и перемоткой
- Сезоны и серии с мгновенным переключением
- Сетка постеров с поиском и фильтрацией (жанр, год, тип контента)
- Фильтры жанра/года учитывают выбранную категорию: «Фильмы + боевик» не показывает сериалы; «Все типы» ищет по всему порталу
- Выбор качества (480p/720p/1080p/Авто; для эпизодов портала варианты берутся из мастер-плейлиста, с пунктом «Авто»)
- Кнопка «Аудио» на плеере: видна, когда у потока есть размеченные аудиодорожки
- Авто-выбор аудиодорожки по предпочитаемому языку (Настройки → Воспроизведение)
- Быстрый старт фильмов (мгновенно по ссылке каталога)
- Возобновление просмотра VOD (сохранение позиции)
- Инвалидация кэша ключа портала (SHA-256)

### Интерфейс
- Hub Page — экран запуска с карточками «Плейлисты», «Портал», «Настройки»
- Полноэкранный режим без полей
- Компактная нижняя панель оконного оверлея: «предыдущий канал» и «запись» — в общем ряду с остальными кнопками; второй ряд появляется только для портала (сезоны/серии/качество/аудио) и архива (пауза, перемотка)
- Трей (сворачивание без остановки воспроизведения)
- Темы оформления (Светлая/Тёмная/Системная): светлая тема полностью консистентна — диалоги настроек, оверлеи плеера (шапка канала, панель управления, EPG-панель) и хаб следуют выбранной теме
- Язык интерфейса (Русский/English), локализация через resw
- Живой разделитель панелей (240–640 px)
- Память окна (позиция и размер восстанавливаются)
- Мини-плеер (Ctrl+M)
- Режим «поверх всех окон» без смены размера (Ctrl+T)
- Автопродолжение последнего канала
- Переключатель вида «Список/Постеры» (только для портала)

### EPG и дополнения
- EPG (XMLTV) с ленивой загрузкой (текущая передача при старте, полный список по клику); название текущей передачи в списке каналов переносится до двух строк
- Многоуровневый кэш EPG: скачанный фид, слитый результат и позиции — старт занимает доли секунды, сеть трогается раз в период обновления (1/3/7 дней); когда срок обновления наступил, программа передач сразу показывается из протухшего кэша, а перекачка идёт в фоне
- Настройки EPG: напоминания, периодичность обновления и глубина архива (1/3/7 дней назад); источники EPG настраиваются для каждого плейлиста отдельно
- Валидация EPG-источника при добавлении (скачивание начала фида, gzip, проверка XMLTV) и статус каждого источника: последняя успешная загрузка или текст ошибки
- Выученные псевдонимы каналов: однозначные совпадения «имя из XMLTV → канал плейлиста» запоминаются и применяются при следующих обновлениях EPG, даже если канал не находится по tvg-id и таблицам имён
- Каналы-двойники с суффиксом «+N» («Первый канал +2», «Россия 1 +4 (Алтай)», «Первый канал +4 HD»): если вариант канала есть в источнике EPG — берётся его точное расписание, иначе программа базового канала сдвигается на N часов; неизменённые передачи переиспользуются при обновлениях EPG, напоминания и подсветка текущей передачи не сбрасываются
- Напоминания о передачах
- Избранные каналы
- Перемещение канала в другую группу и удаление канала из списка (правый клик по каналу); правки переживают обновление плейлиста, восстановление — в настройках плейлиста; действия над каналами заблокированных групп требуют PIN
- Родительский контроль (PIN, дневной лимит просмотра, разблокировка канала по Enter до переключения)
- Запись передач (до 3 параллельных)
- Запланированные записи
- Экспорт/импорт настроек (с шифрованием)
- Адаптивная вёрстка при уменьшении окна: тулбары плеера автоматически масштабируются, список каналов сворачивается на узких окнах и возвращается при расширении; карточки главного экрана масштабируются целиком
- Адаптивная вёрстка при уменьшении окна: тулбары плеера автоматически масштабируются, список каналов сворачивается на узких окнах и возвращается при расширении

### Инфраструктура
- Release: unpackaged сборка под классический установщик
- Инсталятор Inno Setup с выбором языка и декодерами Dolby
- Serilog + Dependency Injection
- MVVM-рефакторинг (ViewModel'и, partial-файлы)
- Юнит-тесты (xunit)
- Оптимизация памяти (nullable-описания EPG, ленивая загрузка)

## Известные особенности

- Задержка от живого эфира ~10–15 с (плата за упреждающую буферизацию)
